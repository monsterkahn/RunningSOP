# Running SOP v1.0.0

Running SOP brings step-by-step guides to your current webpage. Record instructions, add and annotate screenshots, and share reviewed SOP updates through storage you choose.

## Downloads

- **running-sop-extension**: Chrome developer-mode installation package. Extract it and load the `extension/` folder.
- **running-sop-github**: complete source and documentation.
- **running-sop-webstore**: upload package for store maintainers, not a one-click installer.
- **SHA256SUMS.txt**: package checksums.

## Included in this release

Local SOP recording, screenshots with saved annotations, shared publishing, categories, five-point feedback, six interface languages and a standalone storage dashboard. Icons use transparent backgrounds with a subtle dimensional finish.

First installation does not connect to storage or synchronize statistics automatically. Users explicitly select storage and grant the required access. Authored SOP content is not automatically translated.

This historical release and its binary assets are preserved. A GitHub release is separate from Chrome Web Store submission and approval. Native operating-system permission recovery and real two-device shared-storage behavior remain manual acceptance checks. See the repository's installation, privacy and security documents and the MIT license.
