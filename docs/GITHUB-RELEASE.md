Running SOP brings step-by-step guides to your current webpage. Record instructions, add and annotate screenshots, and share SOP updates with your team through user-selected storage.

## Downloads / 下载

- **running-sop-extension**: Chrome developer-mode installation package. Extract and load the `extension/` folder. 完整插件安装素材，解压后在 Chrome 开发者模式中选择 `extension/` 文件夹。
- **running-sop-github**: complete source and documentation / 完整源码及开发说明。
- **running-sop-webstore**: upload package for store maintainers; not a one-click installer / 商店上传专用，不是用户直接安装包。
- **SHA256SUMS.txt**: package checksums / 安装包校验值。

## Included / 本版内容

Local SOP recording, screenshots with saved annotations, shared publishing, categories, five-point feedback, six interface languages, a standalone storage dashboard, and QR links to a mobile reader. Icons use transparent backgrounds with a subtle dimensional finish.

本机录制、截图编辑与标记、共享存储发布、分类管理、五档反馈、六语言界面与独立总表，以及二维码手机阅读入口。统一使用透明底立体图标。

First installation does not connect to storage or sync statistics automatically. Users explicitly select storage and grant required access. SOP content is not automatically translated.

首次安装不自动连接共享存储或同步统计。存储目录由用户主动选择并授权；SOP 原文不会自动翻译。

本 GitHub 分发版不代表已通过 Chrome 商店审核。系统原生授权恢复、真实双机共享验收仍需人工完成。请参阅 README、安装说明、隐私说明和 MIT 许可证。
