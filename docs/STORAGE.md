# 数据与存储

Running SOP 将本机工作数据与用户选择的共享目录分开管理。没有共享目录授权时，本机记录、录制和备份仍可使用。

## 本机数据

Chrome 扩展通过 `chrome.storage.local` 保存本机设置、草稿、录制、备注、本机查看计数及待同步记录。分类不放在扩展本机存储中，而是保存在用户选择的共享目录根下 `categories.json`，与 SOP 正文分开。工作流程匹配主要依据 URL，不读取页面正文或表单值。

录制数据会使用点击控件文字或 `aria-label`、关联标签文字、活动弹窗/标签标题、页面标题及脱敏 URL；它不采集输入字段值。用户手填工作网址和备注也可能标识业务信息。用户主动截图可能捕获可见页面中的任何信息。导出、恢复或分享前，请先检查文件内容。

建议定期导出自己需要保留的数据备份，并存放在符合组织要求的位置。备份文件不会自动上传；清除扩展数据或卸载前，应先确认是否需要留存。

## 可选共享目录

共享目录由用户在 Chrome 文件夹选择器中指定。首次安装不含默认目录；未选定目录时扩展不执行共享读取或写入。授权范围由 Chrome 文件系统访问权限控制，读写分别检查；未获授权时操作会停止并给出提示。

共享内容可能包括：

- 已发布流程及其目录索引；
- 与流程正文分开的分类元数据，例如 `categories.json`；
- 用户明确发布的内容、评分或匿名设备统计文件；
- 由总表工具在用户指定位置生成的展示文件。

发布由用户明确触发。启用目录自动检查后，浏览器运行期间每分钟读取目录；连接统计目录并启用同步后，查看计数和评价记录会自动写入。关闭目录自动检查或统计同步会停止后续后台活动，但不会自动删除已共享的历史数据。分类保存会先校验数据、备份已有分类元数据、检查修订号冲突并在写后回读；它不会改写流程正文。多台设备通过修订号进行乐观冲突检测，不等同于跨设备事务锁。

## 总表生成工具

`tools/build-dashboard.cjs` 从操作者指定的共享目录生成总表。运行前请确认目录来源和访问范围；生成物可能汇总目录元数据或统计信息，应按共享目录的访问策略保管。示例数据位于 `examples/storage/`，仅供测试，不代表真实用户或实际 SOP。

## 示例布局

仓库中的 `examples/storage/` 是可公开的合成样本。它包含演示用通用流程（工作网址为 `https://example.com/work`）、空分类数据以及合成示意图。它不含真实 NAS 路径、内部 SOP、用户截图或生产数据。

## 清理与保留

本机数据可由用户在扩展功能中导出或清除；卸载扩展可能导致 Chrome 删除扩展本机存储。共享目录中的文件由用户或其组织管理，扩展不会擅自清除共享数据。请遵循组织的备份、访问和保留政策。

## 2.5.15：文件夹优先的连接方式

设置页主要操作只有“选择 SOP 文件夹”和“检查连接”。选择本机文件夹，或先在操作系统连接局域网电脑/NAS共享目录后再选该文件夹。扩展不会自动发现、登录或挂载 SMB 服务器，也不会取得跨设备通用的文件路径。

选择器第一次只申请读取权限；识别当前目录或已知子目录 SOP、sop、工作SOP/SOP 中的 catalog.json。找到多个内容库时要求直接选择一个，不擅自挑选。选择无效目录、错误对应文件夹或取消操作时保留旧连接。设置显示目录名称和 SOP 数量，而不把内部标识当作用户地址。

可选“选择目录文件”：只接受内容库中的 catalog.json。单独选择文件不会获得其旁边文件的授权，也不会立即激活新连接；需点击“选择它所在的文件夹”，比对原生文件身份后完成连接。它不是单份 SOP 的导入器。

句柄存储于扩展自己的 IndexedDB，并与本机连接标识绑定。读取不依赖全局“允许访问文件网址”开关；旧 file:// 地址模式仍需要该开关。只有用户选择并连接后才可自动检查；关闭自动检查后可以手动检查，并不因此启用后台轮询。授权失效或共享目录未挂载时提示重选，缓存内容仍需校验，不能当作实时数据。

文件夹连接与发布使用同一个授权目录；发布时单独请求写入许可。旧手工地址模式保留原来的独立发布配置供迁移，选用新文件夹方式后不再显示重复发布选择器。统计同步仍是独立、用户明确启用的功能，不随内容库选择自动开始。

电脑文件夹授权不等于手机 App 的共享目录授权，也不会把本机 file:// 地址变成手机二维码地址。移动阅读仍按 docs/MOBILE-QR.md 的现有方案部署。
