# Running SOP 2.0.0

Create visual procedures, follow them beside your work and share them through a folder you choose. Version 2.0.0 brings the accumulated library, reading and screenshot improvements into one Web Store package.

- **One SOP overview:** browse verified statistics, categories and searchable procedures with step counts. Open retained versions from procedure details.
- **Connected procedures:** arrange SOP relationships in a separate editor and follow an explicit next-SOP card when a verified folder relationship is available. The editor reads the already authorized folder; Save requests write permission and checks for conflicting changes.
- **Clearer reading:** neutral rounded cards group instructions and screenshots. Previews use a 16:6 viewport; full viewing preserves the original image and annotation proportions.
- **Deliberate screenshot masking:** use Mosaic to replace selected image areas before sharing. Existing publications, history and backups retain their earlier copies.
- **Safer publishing:** empty steps are skipped, entirely empty procedures cannot be published, and verified success removes only the unchanged corresponding draft before showing the published SOP. Failed or uncertain writes keep the draft.
- **Shared pages when requested:** install missing index and relationship pages after selecting a folder and allowing writes. Existing pages, including customized pages, are preserved.
- **Local preferences:** choose Light, Dark or System appearance for the overview and relationship pages. Seven flag-free interface languages and a stable browser-local device display name simplify setup.

No new extension permissions or breaking SOP data migration is required. Updating the same extension identity retains existing local settings and data; browser-managed folder permissions may require reauthorization. Fresh installations require explicit storage setup and do not connect or synchronize by default. Screenshots and notes may contain sensitive information; review them before publishing.

Requires desktop Chrome 116 or later. Automated checks use synthetic content and isolated browser profiles. Native permission prompts, physical two-device storage, HTTPS deployment and team statistics remain deferred. This introduction describes the prepared 2.0.0 package; it does not claim Chrome Web Store submission, approval or Google certification.
